# 0.1.0 本地验证记录

本记录对应首次公开准备，日期为 2026-10-17。它描述实际执行的本地检查，不代表远端 CI 或任意真实 MV 的视觉验收。

## 环境与测试

- Windows，Python 3.11.3，外部 FFmpeg / FFprobe，含 libx264、AAC 和 libass。
- 独立虚拟环境执行 `pip install -e .` 成功；依赖为 NumPy 2.4.6、Pillow 13.0.0、OpenCV headless 5.0.0.93。
- 46 项 unittest：45 项通过，1 项因 Windows 缺少创建符号链接的权限跳过。路径越界、错误 ZIP、损坏哈希、跨平台目录冲突等独立测试实际通过。
- 同一套测试也在预装的 NumPy 1.24.0、Pillow 11.3.0、OpenCV 4.7.0 环境通过；这不替代声明依赖的独立安装检查。
- 回归包括全局裁剪相位、小数余量裁剪、末帧、真实 cel 切换、完整 alpha 遮挡、Unicode 工程目录下的 ASS、视频流选择与 native PTS 一致性、完整音频窗口、静音、偏移和恢复。

## 实际 CLI 端到端

`scripts/smoke_demo.py` 在新目录依次创建原创示例、校验、渲染整片与裁剪、取 native 帧、分析音频、打包、校验 ZIP、恢复，再渲染恢复项目。

| 检查 | 结果 |
| --- | --- |
| 完整示例 | 4 秒、120 帧、640×360、30fps |
| 保留相位的预览 | 从 global 0.75 秒开始，2.2 秒、66 帧 |
| 完整片音频 | 全部声明 88,200 samples @22,050Hz，相关约 0.999939，lag 0 |
| 预览音频 | 全部声明 48,510 samples，相关约 0.999955，lag 0 |
| 素材归档 | 7 个声明输入；逐项 SHA-256 校验并实际恢复 |
| 恢复后渲染 | 120 个烧字前合成 RGB 哈希全部相同 |

AAC 解码超出声明窗口的样本单独报告，不用两输入的最短长度掩盖缺失；这些计数不宣称编码音频与 PCM 逐样本相同。RGB 哈希也不证明字幕和有损成片位级相同。

首次样片已检查一张实际编码 PNG，两个几何角色和原创字幕可见；没有据此声称完整动态、真实人物或全片视觉通过。示例仅用于验证流程。
