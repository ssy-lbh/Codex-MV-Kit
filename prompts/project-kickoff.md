# 新 MV 项目起步

```text
请用 Codex MV Kit 帮我制作一个可移动、可复核的 2D sprite MV 项目。

输入：
- 项目目录：[项目目录]
- 音乐及使用权限：[本地文件、授权范围]
- 目标：[画幅、尺寸、fps、时长、风格]
- 原创角色：[AngelA、DemonB 或其他身份]
- 现有素材：[参考图/pose/背景/字体/字幕文件及来源]
- 交付：[视频/工程/归档，是否需要公开]

先读仓库 AGENTS.md、architecture 与 workflow，并检查实际源码和 CLI。
审查输入是否完整，记录来源和授权；不要从旧工程导入私人帧、音乐或日志。
普通本地分析、可逆编辑和预览继续完成；只有真正阻塞的信息再提出问题。

先分析音频的 BPM/phase 候选，明确半拍/双拍歧义和估计分辨率。
建立唯一 global clock；裁剪预览不得重启 epoch。
分开记录 source/native、pose、vocal、display caption 和 FX 事件。
记录实际取帧 PTS 与选帧策略；first-alpha 与 first-clear 分开，不从调色推断起音。

先完成一段有代表性的 2–5 秒对照片段，审查姿势、身份、遮挡、字幕和同步，
再扩展到整片。使用真实整身 cel；镜像正面不能代替实体转身。
有界视频缓存默认 12 帧，不预载整片 RGB。

内置图片生成工具可用时按任务使用；不可用则保存提示词和导入清单。
所有生成结果保存本地文件与 provenance JSON，不自动调用付费 API 或索要 API key。
不把未支持的 schema 字段当成已生效功能。

检查 ceil(duration*fps) 帧及末帧；音频比较覆盖全部声明窗口，不能 min-length 截短，
静音 correlation 为 None。已烘焙字幕不能再叠一套。
最终完整审听/审片，并分别报告自动检查与人工视听状态。
创建 manifest/ZIP/哈希，在新目录真实恢复；恢复成功不代表视觉 QA 通过。
渲染到新文件名，不静默覆盖。外部发布只在本任务已有明确授权时执行。
```
