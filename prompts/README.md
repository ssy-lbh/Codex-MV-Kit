# 可复用提示词

这些模板用于把创作要求变成可检查任务。先替换方括号，再给当前代理；不要把未填写模板直接当作已经确认的角色设定。AngelA 与 DemonB 是通用占位身份。

| 模板 | 用途 |
| --- | --- |
| [project-kickoff.md](project-kickoff.md) | 新歌、资产和工程的起步审查 |
| [character-bible.md](character-bible.md) | 固定原创角色身份与比例 |
| [whole-body-pose.md](whole-body-pose.md) | 真实整身姿势、紧凑手型与转身 |
| [expression-edit.md](expression-edit.md) | 局部表情编辑及非目标差分检查 |
| [layered-background-effects.md](layered-background-effects.md) | 分层场景、遮挡与效果作用域 |
| [cover-layout.md](cover-layout.md) | 精确封面布局、原创文字与字体来源 |
| [source-credit-rights.md](source-credit-rights.md) | 来源、许可、credit 与公开范围 |

模板不保证模型严格遵从，也不保证每个宿主都有图片生成、网页或 GitHub 工具。内置图片生成可用时优先使用，结果保存为本地资产和 provenance JSON；不可用时保存完整提示词和导入清单。不要自动要求 API key、选择付费 API 或上传私人参考图。

默认继续完成普通本地可逆工作，只对影响实施的缺失信息提出必要问题。外部发布按用户已有授权；没有明确发布授权时先完成可审查的本地结果。公共示例不包含真实商业歌曲歌词或来源项目帧。
