# 表情局部编辑 / expression edit

```text
编辑我的原创角色 [AngelA / DemonB]，输入图：[本地整身 cel]。
目标表情：[眼睛、眉毛、嘴形和情绪的具体描述]。
允许变化区域：[面部 mask 或边界]。
保持身份、身体姿势、头发、服装、配件、颜色、画布和透明背景一致。
不增加文字、背景、水印或新配件。

优先使用当前宿主的内置图片编辑工具（若可用），先检查真实输入图。
注意：生成式编辑即使被要求“其他像素完全不变”，也可能改变非目标区域。
不要承诺逐像素不变或只凭肉眼缩略图就声明无变化。

保存输入、原始编辑结果、最终图和 provenance JSON。
对非目标区域做差分，检查头发、衣领、身体轮廓和 alpha 边缘。
如果任务需要严格像素固定，使用已确认的面部 mask 进行本地确定性合成，
保留 mask 与合成步骤，并检查脸部边缘接缝。
说明实际修改范围、是否有非目标漂移，以及人工审核状态。
不要把全图重新生成描述成局部无损修改。
```
